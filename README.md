# gateway — LXS docs

## Capability

The estate **front door**. A plain HTTP reverse-proxy + authorization engine,
all **deny by default**:

- routes are declared in `gateway.json` (generated by eco's `configgen` from
  `ecompose.yml` `access:` declarations, passed via `GATEWAY_CONFIG`);
- a request matching no route returns `403` — never a catch-all forward;
- `public` routes forward as-is;
- `auth` routes require a valid Bearer JWT whose role is authenticated;
- `role:<name>` routes require a JWT whose `role` claim equals `<name>`;
- the gateway verifies the token ONCE at the edge and injects
  `X-Eco-User: <sub>,roles=<role>` upstream (any client-supplied
  `X-Eco-User` is stripped);
- optional `strip`/`rewrite` path-prefix transforms (e.g. `/auth-api/*` →
  `/api/*`).

TLS is deliberately absent: Cloudflare Tunnel terminates TLS at the edge, so
the gateway only speaks plain HTTP on a localhost-reachable port.

## Compose it

```yaml
# ecompose.yml — a `gateway` service flips the estate onto the middleware model
services:
  gateway:
    path: ../../lxs/gateway/backend
    runtimes: [rust]
    binary: gateway
```

Then declare `access.routes` for every HTTP service and an `auth.roles` block.
`eco up --remote` writes `gateway.json` + the service `.env` and exposes the
estate through the gateway port.

## Environment

| Variable | Required | Purpose |
|---|---|---|
| `SERVER_PORT` | yes | Listen port (plain HTTP). |
| `JWT_SECRET` | yes | HS512 signing key; refuses to start without it. |
| `GATEWAY_CONFIG` | yes | Path to the `gateway.json` route table. |
